# Replit.md

## Overview

This is a **Telegram AutoComment UserBot** — a pure Python bot that automatically listens to all joined Telegram channels and posts a random comment on every new post using the user's own account (userbot approach via Telethon).

There is no web dashboard. The project is Python-only.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Main Bot (`main.py`)
- Connects as the user's Telegram account using Telethon + StringSession
- Listens for `NewMessage` events on all joined channels
- On each new channel post: waits 5 seconds, picks a random comment, and posts it as a comment/reply
- Also runs a control bot (using BOT_TOKEN) for managing comments via Telegram commands

### Login Script (`login.py`)
- One-time interactive console script to generate a `TELEGRAM_SESSION` string
- Run via shell: `python login.py`
- Session string is saved to Replit Secrets as `TELEGRAM_SESSION`

### Comment Storage (`comments.json`)
- Comments are stored locally in `comments.json` as a JSON array
- Default pool of 10 comments is seeded on first run
- Managed via control bot commands

### Control Bot (within `main.py`)
- Uses `BOT_TOKEN` to run a second Telethon client as a bot
- Password-protected with `/admin14758`
- Commands: `/status`, `/listcomments`, `/addcomment`, `/delcomment`, `/startbot`, `/stopbot`

## Required Secrets

| Secret | Description |
|--------|-------------|
| `API_ID` | Telegram API ID from https://my.telegram.org |
| `API_HASH` | Telegram API Hash from https://my.telegram.org |
| `BOT_TOKEN` | Bot token from @BotFather |
| `TELEGRAM_SESSION` | Session string generated by `login.py` |

## Key Python Dependencies
- `telethon` — Telegram MTProto client for both userbot and bot functionality
- Python 3.11

## Workflow
- **Start application**: `python main.py`
- **Login (one time)**: run `python login.py` in the Shell
